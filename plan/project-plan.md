# 小Q和小D的一万次恋爱结局 — 仿真模拟交互网页 · 项目计划

## Context（背景与目标）

一款**娱乐向、有真实文献支撑**的叙事型仿真网页。核心体验 = 问卷建模 → Monte Carlo 平行世界仿真 → **故事化报告**（起承转合的爱情叙事，数据驱动文案）。

**核心叙事弧**（用户定稿的方向）：
1. 甜色开场：引导语 + 问卷（暖色插画风）
2. 基线的希望：「在没有客观阻力的情况下，小Q和小D在 **X%** 的平行世界中相爱超过50年（我们以50年为相爱久久）」+ 最长久的一次的故事
3. 灰色的现实：「可是，爱情终究敌不过现实。以下是几个压力场景，请选择——」→ **灰色插画风** → 「压力之下，X% 的世界相爱超过50年」+ 相处最短暂的一次的故事
4. 奇迹的光：「但是，爱情总会有奇迹的不是吗？」→ 某个平行世界历经磨难终成白头偕老的完整故事
5. 哲学余韵：爱情哲学话语 + 分享卡片；折叠的数据附录（星图/曲线/轨迹浏览器/成长点/文献）

产品基调：简约插画风 + 互动动效；小Q和小D **无性别**（形状+颜色区分）；娱乐免责 + 数据本地隐私；模型要素全部标注文献。

已确认决策：React + TS + Vite｜一题双答问卷（每人 12 题）｜7 个情境模块｜头条指标 = P(相爱>50年)｜故事模板套数据。

## 一、视觉与叙事设计

### 美术方向：色彩即情绪（warm → gray → light）
- 暖纸色底 + 细微噪点（SVG noise），手绘感线稿
- 双主角：两只圆润小生物（**无性别特征**）——小Q 偏圆·珊瑚橙，小D 偏高·雾霭蓝；表情状态机（开心/平静/低落/心动/筑墙），答题与故事中实时反应
- **主题双轨**：`theme.warm`（基线/开场/奇迹）与 `theme.gray`（压力场景：去饱和灰调、雨/乌云意象），过场时全局色调渐变（framer-motion 编排）——奇迹章节让暖色与金色光晕回归
- 星尘粒子 canvas、按钮呼吸光效、图表走手绘感定制主题

### 叙事文案系统 `copy.ts`
- 开场（定稿）：「小Q和小D是一对恋人。/ 他们好奇——/ 假如存在一万个平行世界，/ 他们会在多少个世界里，相爱久久。」CTA「开启平行世界的初始设定」
- 转折语（定稿基调）：「可是，爱情终究敌不过现实。」；奇迹语：「但是，爱情总会有奇迹的不是吗？」
- 诗意结局标签：慢性消耗→"在漫长的消耗中，有人先放开了手"；冲动分手→"一次盛怒中的告别"；筑墙→"输给了沉默的世界"；异地→"被距离稀释的世界"；满50年→"白头偕老的世界"
- 哲学结尾：真实可引用名言（Fromm《爱的艺术》、《小王子》等 3–5 句）+ 一句由数据生成的定制结语

### 故事模板引擎 `story/`（新核心模块）
把重放轨迹 → 中文故事段落：
- `templates.ts`：事件类型 × 2–4 个句式变体（冲突/修复/好事分享/新奇/压力/濒临分手被拉回/团聚冲击/里程碑/开场/收尾）
- `generator.ts`：重放选中世界 → 取影响度 top-K 节点（K≈6，按事件冲击与风险尖峰排序，保持时序）→ 填入模板 → 变体由种子哈希选择（同一世界永远讲同一个故事）
- 主角名 + 无性别措辞；年代换算（第 412 周 → "第 8 年的春天"式表述可选）
- 三种策展世界：**最长久的一次**（基线，时长最大）、**最短暂的一次**（压力情境，时长最小）、**奇迹世界**（压力情境下"戏剧度"最高的白头偕老 run；戏剧度 = Σ 存活下来的风险尖峰）

### 屏幕流与线框

**S1 开场**：星尘 + 双主角牵手 + 标题《小Q和小D的一万次恋爱结局》+ 引导语 + CTA + 小字（仅供娱乐·数据仅在本地·无性别设定）

**S2 问卷 — 一题双答**：
```
   第 4 / 12 题          ▓▓▓▓▓░░░░░
       「当意见不合时，我更容易……」
   (小Q头像)                  (小D头像)
   ┌── 小Q ──────┐          ┌── 小D ──────┐
   │ ● 直说但急躁  │          │ ● 先安抚再谈  │
   │ ○ 冷战回避    │          │ ○ 冷战回避    │
   │ ○ 翻旧账      │          │ ○ 翻旧账      │
   └─────────────┘          └─────────────┘
   (答题时对应小生物表情即时变化；两列都已选 → 「下一题」亮起；桌面左右/移动上下)
```
- 关系现状题（在一起多久/阶段/满意感）couple 级居中单卡；保留「预设人设」快捷入口；**单人模式**：任一方可「一键填充随机默认人设」（种子化随机生成，可重抽）——单身用户可模拟"我 × 一个假想的TA"
- **题库抽题（防重复）**：表面措辞每次不同，测量构念恒定——12 个构念（回避/焦虑/情绪稳定性/宜人/尽责/冲突风格各维/好事回应/亲密需求…）各配 2–4 个备选题面（不同情景切入与句式，部分换题型：Likert/迫选/情景单选），会话种子抽取每构念 1 题 → 固定 12 屏、构念全覆盖、题面常新；同种子可复现（分享/复测对齐），每题自带计分映射（方向+权重），抽任何组合参数均成立

**S3 基线仿真 — 万界展开**（暖色）：双主角分岔出光线树（canvas 递归分岔 2s）→ 星场逐点点亮（颜色=结局时长，白头偕老=金色光晕）→ 数字滚动"已展开 6,842 / 10,000 个平行世界" → 真实数据里程碑文案（"第 4,096 个白头偕老的世界，刚刚诞生"）

**S4 基线报告**：
```
   在没有客观阻力的情况下
   小Q和小D在 ✦ X% ✦ 的平行世界中相爱超过50年
   （我们以50年，为相爱久久）
   ─────────────────────────────
   其中最长久的一次——
   「第2年，小D的筑墙让关系跌入谷底；小Q的一次主动修复…」（故事卡）
   次级数据：最漫长47年/最短暂3个月/中位12年（小字）
```

**S5 转折+情境选择**（画面渐灰）：「可是，爱情终究敌不过现实。/ 以下是几个压力场景，请选择——」灰色插画卡片（异地/父母反对/经济/变故/同居磨合/育儿/事业），可多选叠加，选完「推演这些世界」

**S6 压力仿真+报告**（灰色系加载与结果）：「压力之下，小Q和小D在 X% 的平行世界中相爱超过50年」+ 基线 vs 压力对比条/曲线 + **相处最短暂的一次**的故事卡；可「换个压力再试」

**S7 奇迹章节**（暖色回归，金色光）：「但是，爱情总会有奇迹的不是吗？」→ 奇迹世界完整故事（含濒临分手被拉回的节点）+ 该世界轨迹缩略图

**S8 哲学结尾 + 一键复盘**：爱情哲学名言 3–5 句（真实引用）+ 数据定制结语 + 分享卡片（canvas 生成 PNG：标题 + 两世界的 X% 对比 + 双主角插画 + 宇宙编号 + 免责小字）+ **「一键复盘」按钮** → 复盘报告（见下）+ 折叠数据附录：平行世界星图（10k 点，点击重放）、相爱年数分布、生存曲线（手绘风标注"第7年激情退潮线"）、轨迹浏览器（过程预测主入口）、成长点（敏感性，情感化措辞："小D 若把冷战倾向降低一档，白头偕老的世界会多出 N 个"）、文献依据面板

**一键复盘（双人雷达图 + 文字分析）** `src/review/`：
- **双人雷达图**：8–10 个构念维度双轮廓叠加（小Q 珊瑚色 / 小D 雾蓝色），一眼看出形状互补或错位
- **文字分析**：基于文献组合规律生成的适配/摩擦论述——适配如"小Q 的修复主动 × 小D 的高感恩回应 = 冲突转化率高""安全型 × 焦虑型 = 稳定器效应"；摩擦如 焦虑×回避 = "追逃循环"（demand-withdraw, Christensen 1991）、双回避 = "平静的疏离"、低情绪稳定×急躁 = "高振幅争吵"、被动回应×高表达需求 = "错位的欢喜"（Gable 2004 反向）；按两人实际参数触发对应段落，每条溯源文献（组合规则表写入 model-spec）

## 二、模型设计

### 时间与规模
- dt = 1 周，视野 50 年（2600 步）；t=0 = "现在"；默认 N = 10,000（1k 快速档可选）；分手 run 提前退出
- **两次 MC**：先基线（无客观阻力），选定压力情境后再跑一次（同一问卷参数 + 情境修饰器）

### 状态变量与逐周更新（Gottman 2002 离散形式）
```
mood_Q(t+1) = a_Q·mood_Q(t) + b_Q + I_Q(mood_D(t)) + shocks + ε_Q
mood_D(t+1) = a_D·mood_D(t) + b_D + I_D(mood_Q(t)) + shocks + ε_D
```
- 问卷映射参数：`b_i` 设定点、`a_i` 惯性、`σ_i` 噪声、influence 形状、`repair_i`、`capitalization_i`
- `I_i(·)` bilinear：焦虑型=负区斜率陡+修复慢；回避型=平坦+筑墙；安全型=对称+强修复
- 慢变量：intimacy / passion（自然衰减+新奇回补）/ trust_i / commitment_i / satisfaction_i(8周EMA) / alternatives_i
- 内生事件（泊松）：微冲突（四骑士放大、repair 转化）、好事分享（capitalization）、新奇事件、替代漂移
- `commitment_i = sigmoid(w₁·satisfaction + w₂·investments + w₃·(−alternatives) + w₄·network_support)`
- 分手风险 `h_i(t) = h₀·σ(−(commitment_i − κ))·g(慢性低满意)`；罕见"冲动分手-复合"（Dailey）
- **头条指标**：P(存活至 50 年视野末端) = "相爱超过50年"的世界占比

### 情境模块 ×7（可组合 `{modifyParams, addEvents, narrative}`）
| 模块 | 机制要点 |
|---|---|
| ① 异地+团聚 | 异地期冲突↓+理想化偏置；团聚时崩塌+12周冲突尖峰（Stafford & Merolla 2007） |
| ② 父母反对 | network_support↓↓；前~26周承诺亢奋后每周侵蚀（Sinclair et al. 2014） |
| ③ 经济压力 | 设定点↓、σ↑、金钱冲突↑、修复↓（Conger） |
| ④ 重大变故 | 急性冲击+恢复期；恢复=脆弱性 vs 伴侣支持（Karney & Bradbury VSA） |
| ⑤ 同居磨合 | 首52周摩擦↑+幻灭压力；"决定型"减半（Huston PAIR / Stanley） |
| ⑥ 育儿冲击 | 104周高压+investments↑↑ → 双峰结局（Cowan & Cowan） |
| ⑦ 事业忙碌 | 共处↓+溢出冲击↑（Greenhaus & Beutell） |

### 过程预测：种子重放
- 每 run 种子 = hash(masterSeed, r)；xoshiro128**（零依赖）；MC 只存 `{duration, endReason, seed, drama, 里程碑摘要}`
- 点击任一世界 → 确定性重放全轨迹+事件日志 → 图表 + 故事生成共用同一数据源
- 附录策展入口：最常见 / 最漫长 / 最短暂 / 濒危获救的世界们

### 文献复现测试（Vitest 断言方向性结论）
secure×secure > anxious×avoidant；修复技能单调（Gottman 5:1）；父母反对短期↑长期净负；异地期低风险+团聚尖峰；经济压力单调；被动回应更差（Gable）；同种子决定论；状态有界。

## 四、数据记录：首页计数器 + 百分位对比（最小成本方案）

目标文案：「已有 xxx 人开启了小Q和小D的模拟世界」（首页，**以 10,000 为起点**——与"一万个平行世界"呼应）；「你的小Q和小D结局，打败了 X% 的模拟者」；「你的历史最佳平行世界」

**首页模拟计数器**：
- 统一接口 `CounterSource`：`LocalCounterSource`（默认：10,000 象征起点 + localStorage 本地累计）与 `RemoteCounterSource`（KV 原子自增 + 10,000 基线偏移）
- 首页加载时 GET 展示（数字滚动动画），网络失败/离线静默回退 Local，不阻塞不报错
- 用户点击「开启平行世界的初始设定」时 +1（POST 仅自增，无任何载荷）
- v1.0 可纯 Local 上线；接 Remote 只需换实现（与百分位共用同一个 ~30 行 Worker + KV）

**百分位对比两级火箭**：

1. **v1.0 静态基准池（零后端、零成本、上线即有）**
   - 构建期用 `scripts/build-reference.ts` 离线跑引擎：预设人设网格 × 情境组合 × N 种子 → 生成结局分数直方图（101 桶/情境类）→ 打包为 `public/reference-pool.json`（几十 KB）
   - 线上百分位 = 本地查经验 CDF，无任何网络请求；文案诚实表述为「超越了基准宇宙中 X% 的**模拟情侣**」（"模拟者"本就是模拟出来的情侣池，措辞完全成立）
   - 分数定义（写入 model-spec）：score = 0.6·P(相爱>50年) + 0.4·min(中位相爱年数,50)/50，百分位 = 基准池中低于该分数的比例
2. **v1.1 可选升级：真实访客分布（免费额度内）**
   - 用户仿真完成后，匿名上报一条派生指标 `{score, 情境组合掩码, ts}`——**不含任何问卷答案与 PII**
   - 存储：Cloudflare Worker + KV 或 Upstash Redis 免费档（~30 行 worker，桶级原子自增，只存直方图不存原始记录）
   - `percentile/` 模块统一接口 `PercentileSource`，两个实现一换即切，UI 不动
   - 防滥用：会话内限 1 次写（localStorage 标记）、服务端只接受合法桶下标；隐私声明更新为「匿名汇总统计」

**本地个人历史（始终零成本）**：localStorage 存 `{masterSeed, 参数摘要, 头条指标}` 列表 → 结尾页「你的平行世界史」：与上次模拟对比（"比上一次，白头偕老的世界多了 N 个"）、历史最佳；分享卡片带上百分位。

## 五、传播机制（v1.0 已选定，全部零后端）

1. **邀请TA共同填写（传播主引擎）**：把自己的答案压缩编码进 URL hash（LZ-string + base64），一键复制发给TA；TA 打开链接、在TA自己设备上填另一半 → 两半参数合并 → "你们共同的一万个世界"。**零后端实现双人模式**，隐私自决（链接里只有你自愿分享的自己的答案）；每次邀请 = 一次新用户进入
2. **认知差报告**（双人合璧时）：对比"你眼中的你 vs TA 给你打的分"——分歧最大的 2–3 个构念生成话题卡（"原来在TA眼里，你没有自己以为的那么爱冷战"）——天然情侣谈资
3. **分享卡闭环**：canvas 卡片 = 标题 + 两世界 X% 对比 + 双主角插画 + 宇宙编号 + **回流二维码** + 免责小字；奇迹世界可另存"白头偕老证书"版式
4. **隐藏稀有结局**：故事引擎埋 <1% 稀有事件模板（如"第 30 年重逢初遇地点"），抽中者卡片带"隐藏结局"徽章——发现感驱动炫耀式分享

## 七、验证方式

1. `npm run test`：决定论、有界性、文献复现套件全绿
2. `npm run dev` 全叙事走查：开场→12题→万界展开→基线X%+最长故事→灰色转折选压力→压力X%+最短故事→奇迹世界故事→哲学结尾→一键复盘（双人雷达图+文字分析）→分享卡下载→附录点开"仅存的十年长跑"可重放
3. 故事引擎快照测试：同种子生成的故事文本稳定；事件节点数与数据一致
4. 抽题测试：任意种子抽取均为 12 构念全覆盖、同种子可复现、计分映射有界
5. 邀请链接：编码→解码往返参数一致；链接仅含自愿分享的自己一方答案；双认知差报告仅双人模式出现
6. 性能与帧率：加载动效不掉帧；10k 仿真 <5s
7. 复盘：雷达图两轮廓与参数一致；文字分析触发规则与两人参数匹配、方向与文献一致
8. 百分位与计数器：`build-reference` 固定种子可复现、CDF 查值单调；计数器离线回退 Local 不报错；localStorage 个人历史读写正常
9. 文案检查：无"他/她"、概率化措辞、免责与隐私位置
