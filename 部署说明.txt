小Q和小D的一万次恋爱结局 —— 部署说明（给发布的朋友）
========================================================

这是什么
--------
一个纯静态网站（只有 HTML/CSS/JS，无后端、无数据库、无 Node 环境）。
压缩包里的内容就是构建产物，直接托管即可，不需要任何编译步骤。

文件清单
--------
index.html            入口
assets/               JS/CSS（含一个 Web Worker 文件，必须一起上传）
reference-pool.json   百分位基准数据（必须一起上传）

腾讯云 COS（推荐）
------------------
1. 控制台 → 对象存储 → 创建存储桶（地域随意，访问权限：公有读私有写）
2. 上传：把压缩包里的全部内容（index.html、assets、reference-pool.json）直接上传到桶根目录
   ※ 注意是上传"压缩包里面的文件"，不是外面再套一层文件夹
3. 基础配置 → 静态网站 → 开启，默认索引文档填 index.html
4. 用静态网站分配的域名访问即可
5. 如需绑定自己的域名：国内节点需要域名完成 ICP 备案

阿里云 OSS
----------
1. 创建 Bucket，读写权限：公共读
2. 上传同样的文件内容到根目录
3. Bucket 配置 → 静态页面 → 默认首页 index.html
4. （同样：自定义域名需备案）

或任意服务器（nginx 等）
------------------------
把压缩包内容解压到站点根目录即可，例如 nginx 的 html/ 目录。
无需任何特殊配置；建议开启 gzip。

注意事项
--------
- 路径已使用相对路径（./），放在任何子目录下都能正常工作
- 必须通过 http/https 访问（不能直接双击 index.html 用 file:// 打开）
- 一切计算都在访问者自己的浏览器里完成，服务器零负载、零隐私数据
