# 小Q和小D的一万次恋爱结局

一个基于心理学文献的**平行世界恋爱仿真**互动网页（仅供娱乐）。

> 小Q和小D是一对恋人。
> 他们好奇——
> 假如存在一万个平行世界，
> 他们会在多少个世界里，相爱久久。

## 玩法

1. **初始设定**：12 道题为一题双答（同时为小Q和小D作答），题目从题库按构念抽取，每次打开措辞不同；也可用预设人设或「随机两人」快速开始；单身可以让另一半一键随机
2. **万界展开**：10,000 次 Monte Carlo 仿真在 Web Worker 中运行，每个光点都是一个真实模拟的平行世界（金色 = 相爱久久）
3. **基线报告**：在没有客观阻力的情况下，小Q和小D在 X% 的平行世界中相爱超过 50 年 + 最长久的一次的故事
4. **灰色现实**：叠加压力场景（异地+团聚 / 父母反对 / 经济压力 / 重大变故 / 同居磨合 / 育儿 / 事业忙碌，可组合），看压力改写结局
5. **奇迹**：戏剧度最高的白头偕老世界的完整故事
6. **结尾**：哲学引言 + 一键复盘（双人雷达图与适配/摩擦分析）+ 数据附录（**轨迹浏览器**：点击星图任意世界查看逐周轨迹与事件节点）+ 原生 canvas 分享卡片
7. **邀请模式**：把自己的答案编码进 URL 发给TA，零后端的"共同填写"

## 模型（简述）

- **动力学骨架**：Gottman 等《The Mathematics of Marriage》(2002) 的耦合方程——双方情绪通过 bilinear influence function 相互影响，含依恋风格差异、筑墙（stonewalling）与修复（repair）机制
- **压力框架**：Karney & Bradbury (1995) VSA 模型——外部事件经"脆弱性"放大、"适应过程"衰减
- **分手规则**：Rusbult 投资模型（满意 + 投入 − 替代 + 网络支持）驱动的每周风险率
- **文献复现测试**：`tests/literatureReproduction.test.ts` 断言模型方向性复现 7 条文献结论（追逃循环更不稳定、父母反对长期净负、异地团聚后风险尖峰等）

完整规范见 [`plan/model-spec.md`](plan/model-spec.md)，项目计划见 [`plan/project-plan.md`](plan/project-plan.md)。

```bash
npm install
npm run dev        # 开发服务器
npm test           # 34 个测试（决定论 / 有界性 / 文献复现 / 故事引擎）
npm run build      # 类型检查 + 构建
npx tsx scripts/calibrate.ts      # 人设校准对照表
npx tsx scripts/scenario-check.ts # 情境效应诊断
```

## 工程要点

- **确定性**：xoshiro128\*\* 种子化 RNG；每世界种子 = hash(masterSeed, runIndex)，点击任意世界可完整重放（Monte Carlo 与重放共用同一引擎路径，有一致性测试守护）
- **性能**：10,000 次 × 50 年周仿真约 4–5 秒（Web Worker，主线程不卡）；星图/加载动效为单 canvas
- **隐私**：无后端、无埋点，所有计算与数据仅在本地浏览器完成
- **无性别**：小Q和小D以形状与颜色区分，全站文案避免性别指代
